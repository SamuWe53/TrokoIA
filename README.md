# Troko — Guía de componentes

Página web interactiva para construir **Troko**, una mini-IA con voz y ESP32-S3.

## Publicar en GitHub Pages (paso a paso)

1. Crea un repositorio nuevo en GitHub (nombre: `troko-ia`, visibilidad: **público**)
2. Sube los 3 archivos: `index.html`, `README.md` y `.nojekyll`
3. Ve a **Settings → Pages → Source: Deploy from a branch → Branch: main → / (root) → Save**
4. Espera ~1 minuto → tu página estará en `https://<usuario>.github.io/troko-ia/`

> ⚠️ El archivo `.nojekyll` es OBLIGATORIO. Sin él GitHub no sirve la página correctamente.
